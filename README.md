# BWD Meeting Hub
**ระบบจัดการประชุมและติดตามภารกิจ โรงเรียนบ้านวังด้ง**

## R2: พื้นที่ทำงานร่วมกัน (กำลังเตรียมเปิดทดสอบ)

- หน้าเว็บใหม่: **[workspace.html](./workspace.html)** — เข้าสู่ระบบด้วย Supabase Auth และแสดงเฉพาะการประชุม/งานที่มีสิทธิ์
- ฐานข้อมูล/RLS/RPC และ private storage: **[supabase/migrations](./supabase/migrations)**
- คู่มือการตั้งค่าระบบและข้อกำหนดก่อนใช้ข้อมูลจริง: **[docs/R2_SETUP.md](./docs/R2_SETUP.md)**
- สถานะ: **สร้างโค้ดแล้ว แต่ยังไม่ได้สร้าง/เชื่อม Supabase project หรือทดสอบสิทธิ์หลายบัญชีจริง** หน้า workspace.html จะยังไม่เปิดให้เข้าสู่ระบบจนกว่าจะตั้งค่า
- มี: ร่างประชุม วาระ ข้อสรุป รายงานประชุมส่งตรวจ งานมอบหมาย/ส่งตรวจ/ตรวจรับ หลักฐานส่วนตัว และติดตามงานข้ามการประชุม
- ยังไม่มี: ระบบส่งแจ้งเตือนอัตโนมัติ การเชิญทางอีเมล การส่ง Google Docs โดยตรง และการรับรองรายงานของกรรมการอย่างเป็นทางการ

> ⚠️ **ห้ามบันทึกข้อมูลจริงก่อนผ่าน R2 security acceptance และตั้งค่าสิทธิ์/สำรองข้อมูลจริง**

## R1: รุ่นทดลองในเครื่อง

เว็บต้นแบบสำหรับการประชุมกรรมการสถานศึกษา ประชุมครู ประชุมฝ่ายบริหาร การประชุมคณะทำงาน และการประชุมอื่น ๆ โดยออกแบบวงจรการทำงาน **เตรียมวาระ → บันทึกข้อสรุป → มอบหมายงาน → ติดตามสถานะ → ตรวจรับ (ระยะถัดไป)**

> ⚠️ **R1 เป็นรุ่นทดลองเท่านั้น:** เก็บข้อมูลใน localStorage ของเบราว์เซอร์เดียว ไม่มีระบบผู้ใช้/สิทธิ์ ข้ามเครื่อง ซิงก์ข้อมูล อนุมัติมติ หรือแจ้งเตือนจริง **ห้ามใส่ข้อมูลบุคคล/รายงานประชุมที่เป็นความลับ** ก่อนเปิดใช้ฐานข้อมูลที่ปลอดภัย

## ทดลองใช้งานในเครื่อง
เปิด \`index.html\` ในเบราว์เซอร์ หรือรัน static server ภายในโฟลเดอร์ repo เช่น \`python -m http.server 8000\` แล้วเปิด \`http://localhost:8000\`.

การตั้งค่า GitHub Pages ยังไม่ได้รับการยืนยัน ไม่ควรเข้าใจว่าโดเมนหรือ URL ได้เผยแพร่แล้ว

## ความสามารถ R1
- หน้าภาพรวม การประชุม ภารกิจ สำหรับมือถือและคอมพิวเตอร์
- สร้างร่างการประชุมโดยเลือกประเภท ระบุวัน/สถานที่ได้
- เพิ่มหัวข้อวาระ 1–5 ในแต่ละการประชุม
- บันทึกร่างข้อสรุปหรือบันทึกจากที่ประชุม (ยังไม่ใช่การรับรอง)
- เพิ่มภารกิจที่เชื่อมไปยังการประชุม/วาระ ระบุผู้รับผิดชอบและกำหนดส่ง
- ติดตามสถานะงาน: ยังไม่เริ่ม / กำลังดำเนินการ / ติดปัญหา / ส่งให้ตรวจ
- ค้นหาการประชุม กรองสถานะภารกิจ ส่งออก/นำเข้าข้อมูล **ทดลอง** JSON
- มีร่างหัวข้อจากการเตรียมประชุมครั้งแรกเป็นข้อมูลตัวอย่าง **ไม่มีมติที่บันทึกแล้วหรือผู้ได้รับมอบหมายจริง**

## ก่อนเปิดใช้งานจริง
ต้องมีระบบยืนยันตัวตนและสิทธิ์รายประชุม (รวมผู้เข้าประชุมภายนอก), ฐานข้อมูลที่มี Row Level Security, ประวัติการแก้ไข, การรับรองมติ/ตรวจรับงาน, นโยบายเก็บเอกสารและข้อมูลบุคคล, การสำรองข้อมูล และระบบแจ้งเตือนจริงที่ได้รับอนุญาตแล้ว

Repository นี้เป็น **public** จึงจัดเก็บเฉพาะโค้ด แม่แบบ และข้อมูลตัวอย่างที่ไม่ระบุตัวบุคคล

## สถานะ
- R1: เริ่มใช้งานต้นแบบในเครื่องได้ (รอทดสอบ UX และอุปกรณ์จริง)
- R2: ยังไม่เริ่มระบบผู้ใช้และฐานข้อมูลส่วนกลาง
- R3: ยังไม่เริ่มระบบแจ้งเตือนจริงและ AI ช่วยบันทึก
